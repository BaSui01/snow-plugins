# 会话文件统计 1.1.4

需配套宿主构建，UI/重启未验收。历史最低宿主 0.4.16 不代表本版完整任务历史兼容；尚无已确认支持新增任务历史能力的正式宿主版本，不猜改市场 `minAppVersion`。按对应专属标签下载安装包。

- 内联 Diff 重构为 Side-by-Side 左右双栏对比，左侧变更前、右侧变更后，列内自适应折行防溢出，中线清晰隔离，表头与行号对齐。
- 移除多余的原始 patch 详情、换行开关及占行快照文本，展开即入代码对比；完整说明保留于滚动区悬停。
- 优化无末尾换行展示为单行弱化提示，不重复显示双行文本。
- 子代理会话在无专属任务快照时静默隐藏，消除历史不可用假报错。
- 清理三语 JSON 语言包中 69 个废弃键值，精简至活跃的 28 个键。
- 展开时列表高度上限扩展至 560px 避免过早滚动。
- 每次用户触发的 Agent 任务独立统计，包含同任务工具多轮、steer 和子代理；排队下一任务实际启动后另计，暂停恢复不换归属。
- 清单显式选择 `taskHistory: true`，只展示宿主 `context.task` 冻结快照；旧卡片与 diff 绑定该次结束回复，下一任务运行不隐藏，重开/重启从持久工具记录引用恢复。
- 配套宿主在真实外层收尾保存稳定任务 ID 与持久记录引用到结束消息 `raw_json` 元数据，不另存正文或差异；旧历史缺可靠边界、缺失记录或未持久结束回复时显示兼容提示，不回退累计。此能力需要本次宿主构建，尚无已确认正式发行版本。
- Ctrl（Windows/Linux）/Command（macOS）点击仍调用 `panels.openFile`，需要宿主公开并授权该动作；v0.4.16 的 footer 没有 write API，但内联 diff 不依赖该 API。
- 本次版本与说明更新已通过现有 `python scripts/release.py validate`（两个插件清单、资源、JSON 与 JavaScript 语法）及 `git diff --check` 静态校验；不代表安装或交互验收。

# 会话文件统计 1.1.2（已发布版本）

## 更新内容

- 移除列表交替背景，保留悬停反馈。
- 普通点击列表项通过受限 `panels.openFileDiff` 打开宿主只读 diff 阅读器，直接展示最新已采集 patch，不伪造全文或读取磁盘。
- Windows/Linux 使用 Ctrl+点击、macOS 使用 Command（⌘）+点击，通过 `panels.openFile` 打开当前文档；删除、非法或明确远程路径会显示原因。
- 标题和展开箭头使用宿主 Lucide 图标，图标在背景框内水平、垂直居中。
- 按动作分别探测宿主能力，保留生命周期与失败提示，补齐简体中文、繁体中文及英文交互文案。

## 兼容性与本地验证

- 基础统计最低要求 Snow App v0.4.16；该版 footer 未开放 write API，不能提供本版点击导航，安装插件不会更新宿主。
- 完整交互作为 Snow App **v0.4.17 的配套新功能**安排，需要 footer 受限 `panels.openFile` 与 `panels.openFileDiff`。配套源码已实现并构建通过，正式发行版及实际交互尚未验收；不宣称 v0.4.16 已支持。
- 差异是宿主采集的最新快照，可能截断，不代表当前文件、会话累计或最终 Git 净差异；缺少文本 diff 或接口时明确提示。
- 插件现有静态校验、配套宿主类型检查及完整构建通过。实际点击、视觉与三平台验收尚未完成；本地安装成功不等于交互已验证。
- 市场 `minAppVersion` 保持 **0.4.16**，允许旧宿主使用基础统计，缺少导航动作时显示升级提示。正式发布工作流会创建市场更新 PR，需维护者审核合并，不自动生效。DOM 图标适配依赖已核实的 Lucide 组件节点结构，宿主升级时需重新验证。

# 会话文件统计 1.1.1（历史版本）

## 更新内容

- 无有效文件记录时隐藏卡片，不再显示空统计。
- 路径按钮可在支持 `panels.openFile` 的宿主回复插槽中请求打开右侧文件阅读器；删除记录、无绝对路径或接口缺失时禁用。
- 统计口径和历史覆盖说明改为悬停提示，保留读取、打开错误及行数未采集状态。
- 使用宿主主题变量、按卡片宽度响应布局，并补充简体中文、繁体中文和英文打开文件提示。

## Snow App 兼容性

- 基础统计最低要求 **Snow App v0.4.16**：该正式版包含回复插槽 v1 和增强文件追踪接口。v0.4.15 不具备这些基础能力。
- **v0.4.16 的回复插槽未开放 write API，点击打开文件不可用**。本插件探测能力后禁用路径按钮，仍展示统计；重装插件不会给宿主增加接口。
- 完整点击打开功能需要另有已验证的宿主构建，在 footer API 中公开受限 `panels.openFile` 动作。目前未确认包含它的正式宿主发行版，不宣称升级到 v0.4.16 即可打开文件。
- ZIP 构建、语法和资源检查不替代实际宿主视觉及交互验收。自定义主题、极窄布局、打开失败等场景仍需在实际宿主验收。

最低版本写入市场索引，用于阻止低版本安装；并不意味着所有可选功能在最低版本可用。市场更新 PR 需维护者审核，本次发布不自动合并。
