# 会话文件统计

在 Snow App 最新已结束回复下方展示**当前会话及其子代理已记录的文件数量和清单**，方便回顾本次会话涉及哪些文件。仅提供回复卡片，**没有独立面板、路径筛选或采集覆盖详情展开区**。

## 安装与使用

1. 在 Snow App 插件管理页点击「从目录安装」。
2. 从您下载或克隆仓库的实际位置选择 `plugins/session-file-count`，确认目录内直接包含 `plugin.json`。
3. 确认插件已启用，打开会话，待 Agent 本轮结束后查看最新回复正文下方、消息操作按钮之前的文件卡片。

卡片默认显示 **4 条文件路径**；超过 4 条时可展开全部，再收起。会话运行、暂停或正在停止时不显示。没有有效文件记录时，卡片也不显示，无论是否存在覆盖记录；不会展示「尚无已记录文件」的空卡片。

**普通点击列表项**：在宿主右侧内置 diff 阅读器查看该文件最新记录的差异，不在卡片内展开，也不修改文件。路径按钮支持 Enter / 空格；点击行数或行内空白也执行同样的导航。

**Windows / Linux 使用 Ctrl+点击，macOS 使用 Command（⌘）+点击**：打开宿主内置文档阅读器，查看文件当前内容。修饰键遵循宿主通过 `navigator.platform` / `navigator.userAgent` 判断系统的约定。删除记录、非绝对路径、明确标识为 SSH 的记录或宿主缺少打开接口时显示原因，不猜测路径归属。

差异来自宿主公开的 `record.diff.patch`，可能被截断，不代表当前磁盘内容、整个会话累计差异或最终 Git 净差异。缺少 patch 或为二进制文件时显示「没有可展示的文本 diff」，不会回取更早记录、读盘或扫描 Git。

列表没有交替背景，仅保留悬停反馈。标题和展开箭头使用宿主 `api.ui.icon()` 提供的 Lucide 图标，标题图标在背景框内水平、垂直居中。DOM 插槽使用已核实的 Lucide forwardRef 组件 `iconNode` 数据生成 SVG；宿主若变更该组件结构，需要重新验证此适配，不会回退为自带图标。

无需打开插件面板或配置。禁用或卸载会移除插件卡片，宿主已有的采集与历史记录不因此删除。重复安装同一标识会更新已安装副本；修改源码目录不会自动更新已安装副本。

插件标识为 `com.snow.session-file-count`，清单版本为 `1.1.2`（本地开发版，尚未发布）。本版变更与宿主兼容说明见 [发布说明](RELEASE.md)。

## 如何理解统计

| 显示内容 | 实际含义 |
| --- | --- |
| 已记录文件数 | 当前会话跨轮次累计的有效文件记录，包含其子代理；按宿主文件身份去重，不是编辑次数、整个仓库改动数或最终净 Git 差异 |
| 文件路径 | 优先显示相对于采集根目录的路径；无法安全转成相对路径时保留原路径 |
| `+` / `−` 行数 | 每个文件最新记录中可计算的差异行数；卡片汇总这些已知行数，不是从会话开始累计的新增、删除或净差异 |
| 行数未采集 | 终端来源、二进制文件或没有可用差异文本，不能解释为新增和删除均为 0 |

同一文件由文件工具与终端重复记录时，有规范身份的记录只计一次；旧历史可能缺少身份键，路径写法不同的记录不一定能合并。统计口径、旧记录或缺失覆盖数据的说明放在悬停提示中，不再显示常驻解释性小字；**不提供完整覆盖详情**。行数未采集仍保留为状态，不能当作 0；读取失败仍显示必要错误提示，缺少文本差异或导航能力时明确显示原因。最新记录不可计算行数时，不回取更早的差异充当当前行数。

## 主题、响应式与多语言

- 颜色、背景、边框、圆角及滚动条使用 Snow 宿主主题变量，不固定为深色；增删行数使用主题语义文字色，适配浅色和深色。主题切换时随 CSS 变量更新。
- 响应式以卡片实际宽度为准，不依赖窗口宽度：卡片不超过 360px 时，路径换行、行数另起一行，适应拖动面板分隔条后的窄聊天区；宽卡片路径省略，悬停可查看完整路径。基础 Flex 换行在不支持容器查询时仍可用。
- 接入 `api.t` / `api.locale` 与宿主语言包加载机制，提供简体中文、繁体中文、英文；宿主语言切换会重新挂载卡片。标题、展开按钮、状态、悬停及错误提示均使用语言包，差异数字按宿主语言格式化。
- 上述为源码层面的适配；每个预设、自定义配色和极窄宽度的视觉效果仍需在实际宿主中验收。自定义主题的对比度取决于其主题变量。

## 宿主要求与采集边界

基础统计最低要求 **Snow App v0.4.16**，它已包含通用回复插槽和增强文件追踪元数据。配套改动通过 [PR #179](https://github.com/MayDay-wpf/snow-app/pull/179 "会话文件统计所需回复插槽及文件追踪增强已合并") 合并并进入 v0.4.16；v0.4.15 不包含这些能力。安装插件不会更新宿主。

完整点击功能需要支持回复插槽受限 `write` API 的宿主构建，单独重新安装插件不会更新宿主。本次源码已实现这些接口，但尚未确认正式发行版本：

- `api.write.run("panels.openFileDiff", { filePath, patch, changeType })`：打开宿主只读差异阅读器，patch 直接取最新记录，`create/edit/delete` 映射为 `added/modified/deleted`，不读取磁盘、不伪造旧新全文。
- `api.write.run("panels.openFile", { filePath })`：修饰键点击打开当前本地文档；不向插件返回文件内容。
- 使用 `api.write.domains()` 分别探测动作权限；旧宿主仍显示统计，点击时提示所缺能力。两个动作均无需额外隐私声明，回复插槽不开放其他写动作。
- 导航返回 `ok` 只表示请求被接受，不代表文件已成功读取或 diff 已成功渲染；文件加载失败由宿主阅读器显示。

- 缺少回复插槽时不会加载卡片，也没有独立面板或聊天 DOM 注入替代。
- 插槽已加载但增强数据契约不满足时会提示升级；读取失败或缺少记录时不会展示假统计。
- **文件采集由宿主完成，插件只展示记录。**文件工具成功写入可以留下明确目标记录；终端采集主要比较命令执行前后、限定范围内的内容变化。
- 人工或外部进程并发修改、后台 / PTY、SSH、外部路径，以及同一命令内修改后恢复原样等，不保证被采集或正确归属。
- 扫描范围、文件数量、内容大小、时间预算、隐私过滤、结果截断与旧历史都可能导致缺口。Git 扫描排除 ignored；非 Git 扫描也会排除常见构建、依赖目录和符号链接等。

**数量仅代表已取得的记录，不是完整审计。没有记录不等于没有修改，已记录也不等于最终仍有净改动。**

## 隐私与开发参考

插件只订阅公开 `runtime` 元数据中当前会话的文件记录和覆盖状态，不读取消息正文，不扫描 Git、不执行命令、不联网、不修改项目文件，也不持久化路径或差异。卡片会显示宿主提供的文件路径；分享截图时请留意路径中可能包含的敏感信息。

运行入口是 `footer.js`，清单仅声明 `contributions.messageFooters`，`panels` 为空。宿主契约使用 `messageFooterVersion === 1`、`fileChangeTrackingVersion === 1`，以及会话对应的 `fileChangeStats` / `fileChangeCoverage`。接口与生命周期详情请查阅 Snow App 内置文档「插件开发与安装」及「插件元数据域参考」。
