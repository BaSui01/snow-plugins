# 会话文件统计

在 Snow App **每次 Agent 任务的结束回复下方**展示该任务及其子代理已记录的独立文件数量和清单，不累计、不继承前次任务。仅提供回复卡片，**没有独立面板、路径筛选或采集覆盖详情展开区**。

## 安装与使用

1. 在 Snow App 插件管理页点击「从目录安装」。
2. 从您下载或克隆仓库的实际位置选择 `plugins/session-file-count`，确认目录内直接包含 `plugin.json`。
3. 确认插件已启用，打开会话，待 Agent 本次任务结束后查看对应结束回复正文下方、消息操作按钮之前的文件卡片。

卡片默认显示 **4 条文件路径**；超过 4 条时可展开全部，再收起。下一任务运行、暂停或正在停止时，已经结束任务的旧卡片仍保留在原回复下方。没有有效文件记录时，卡片也不显示，无论是否存在覆盖记录；不会展示「尚无已记录文件」的空卡片。

**普通点击列表项**：在该文件下方内联展开/收起最新记录的左右分栏（Side-by-Side）diff，左侧展示变更前（旧内容及旧行号，删除高亮），右侧展示变更后（新内容及新行号，新增高亮），中间以清晰垂直分割线分隔；上下文行双侧对齐。不再调用 `panels.openFileDiff`，也不读取当前文件或修改文件。路径按钮支持 Enter / 空格，并提供展开状态与关联区域；点击行数或行内空白也执行同样的展开/收起。差异区域内点击、选择文本和滚动不会触发列表项操作。原有默认 4 条与展开全部交互保持不变；同一挂载中收起列表保留每个文件的展开状态，生命周期取消时清理；后续任务不替换前次卡片的文件记录或 diff。

**Windows / Linux 使用 Ctrl+点击，macOS 使用 Command（⌘）+点击**：打开宿主内置文档阅读器，查看文件当前内容。修饰键遵循宿主通过 `navigator.platform` / `navigator.userAgent` 判断系统的约定。删除记录、非绝对路径、明确标识为 SSH 的记录或宿主缺少打开接口时显示原因，不猜测路径归属。

差异来自宿主公开的 `record.diff.patch`，可能被截断，不代表当前磁盘内容、整个会话累计差异或最终 Git 净差异。缺少或空 patch、二进制记录分别明确提示，不会回取更早记录、读盘或扫描 Git。通过 `textContent` 安全渲染原始文本，按 hunk 展示旧/新行号、增删背景；文件头和无末尾换行标记不占内容行号。省略计数的 hunk 按 1 行解析，零行范围不生成不存在的行号，遇到无法解析或不完整的 hunk 提示可能截断，不补造内容。当前契约没有独立的截断标志，因此始终提示快照可能不完整；无法判断宿主截断的全部情况。差异可横向滚动，滚动区高度最多 320px；卡片最多渲染 patch 前 1000 行并明确提示显示限制。

展开后直接进入左右双栏对比，不再常驻多余工具栏；完整快照与截断警示保留在差异区域悬停提示中，不展示冗余的原始 patch 详情。左右分栏按编辑块配对对齐变更行，上下文双侧同步；表头明确标注「变更前」与「变更后」，行号与代码独立列排布。无末尾换行标记保留单行弱化提示，不重复显示双行文本。未实现行内字符高亮，避免把不可靠的删增行配对误认为替换关系。展开状态仅属当前 DOM，列表重建或重新挂载后恢复默认。

列表没有交替背景，仅保留悬停反馈。标题和展开箭头使用宿主 `api.ui.icon()` 提供的 Lucide 图标，标题图标在背景框内水平、垂直居中。DOM 插槽使用已核实的 Lucide forwardRef 组件 `iconNode` 数据生成 SVG；宿主若变更该组件结构，需要重新验证此适配，不会回退为自带图标。

无需打开插件面板或配置。禁用或卸载会移除插件卡片，宿主已有的采集与历史记录不因此删除。重复安装同一标识会更新已安装副本；修改源码目录不会自动更新已安装副本。

插件标识为 `com.snow.session-file-count`，清单版本为 `1.1.5`。本版变更与宿主兼容说明见 [发布说明](RELEASE.md)。

## 任务边界与历史恢复

一次用户触发的外层 AI loop 是一个任务。模型/工具多轮、任务自己的子代理与运行中 steer 同属一个任务；FIFO 排队消息实际启动时另建任务；暂停恢复保持原归属，工具消息不是新任务。

宿主在真实外层收尾、排队下一任务启动之前，将稳定任务 ID 和已归属的持久消息记录 ID 保存到该次结束 assistant 回复的现有元数据中。只保存引用，不另存聊天正文、文件内容或 patch；恢复时复用原始持久工具记录构建冻结快照。切换、重开会话或重启后从这些引用恢复旧卡片；后续同文件改写不会更新旧 diff。无文件任务隐藏自己的空卡片，不借前次记录。

断流、异常中断、工作流续跑等待、缺少源记录或没有可靠任务结束归属的历史静默隐藏，不弹出历史不可用或缺少记录的报错卡片，不伪造迁移，不回退为会话累计。子代理会话的工具操作已归属于父任务主卡片，在进入子代理视图且未提供专属任务快照时同样静默隐藏。分叉/导入若未重映射历史引用，不跨会话读取原记录冒充分叉任务。

## 如何理解统计

| 显示内容 | 实际含义 |
| --- | --- |
| 已记录文件数 | 本次用户触发的 AI loop 内有效文件记录，包含本任务自己的子代理；按宿主文件身份去重，不是编辑次数、整个仓库改动数或最终净 Git 差异 |
| 文件路径 | 优先显示相对于采集根目录的路径；无法安全转成相对路径时保留原路径 |
| `+` / `−` 行数 | 每个文件最新记录中可计算的差异行数；卡片汇总这些已知行数，不是从会话开始累计的新增、删除或净差异 |
| 行数未采集 | 终端来源、二进制文件或没有可用差异文本，不能解释为新增和删除均为 0 |

同一文件由文件工具与终端重复记录时，有规范身份的记录只计一次；旧历史可能缺少身份键，路径写法不同的记录不一定能合并。统计口径、旧记录或缺失覆盖数据的说明放在悬停提示中，不再显示常驻解释性小字；**不提供完整覆盖详情**。行数未采集仍保留为状态，不能当作 0；读取失败仍显示必要错误提示，缺少文本差异或导航能力时明确显示原因。最新记录不可计算行数时，不回取更早的差异充当当前行数。

## 主题、响应式与多语言

- 颜色、背景、边框、圆角及滚动条使用 Snow 宿主主题变量，不固定为深色；增删行数使用主题语义文字色，适配浅色和深色。内联 Diff 隔离聊天正文的表格奇偶行背景与单元格文字色，新增/删除行使用宿主的语义背景及文字色，上下文、表头和行号使用对应主题色。主题切换或自定义配色更新时，已展开的 Diff 随 CSS 变量实时更新，无需重新展开。
- 响应式以卡片实际宽度为准，不依赖窗口宽度：卡片不超过 360px 时，路径换行、行数另起一行，适应拖动面板分隔条后的窄聊天区；宽卡片路径省略，悬停可查看完整路径。基础 Flex 换行在不支持容器查询时仍可用。
- 接入 `api.t` / `api.locale` 与宿主语言包加载机制，提供简体中文、繁体中文、英文；宿主语言切换会重新挂载卡片。标题、展开按钮、状态、悬停及错误提示均使用语言包，差异数字按宿主语言格式化。
- 上述为源码层面的适配；每个预设、自定义配色和极窄宽度的视觉效果仍需在实际宿主中验收。自定义主题的对比度取决于其主题变量。

## 宿主要求与采集边界

**1.1.5 版本：左右双栏对比、断流/未完成任务静默隐藏与独立任务历史需配套本次宿主源代码改动与原生模块构建，UI/重启未验收。尚无已确认正式发行版本支持 `taskHistory` / `context.task`。旧宿主仅显示兼容提示，不再用累计统计替代独立任务。以下 v0.4.16 基础能力说明属于已发布版本历史，不代表 1.1.5 的完整任务历史兼容。**

基础统计最低要求 **Snow App v0.4.16**，它已包含通用回复插槽和增强文件追踪元数据。配套改动通过 [PR #179](https://github.com/MayDay-wpf/snow-app/pull/179 "会话文件统计所需回复插槽及文件追踪增强已合并") 合并并进入 v0.4.16；v0.4.15 不包含这些能力。安装插件不会更新宿主。

市场最低版本为 **Snow App v0.4.16**，对应回复插槽及增强元数据能力。**普通点击内联 diff 在插件中渲染，不需要 footer 的 diff write 能力，也不调用 `panels.openFileDiff`**；已发布安装包的行为见对应发行说明。修饰键文件导航仍需实际包含以下接口的宿主构建，配套能力作为 **v0.4.17 的新功能**安排；正式版及跨系统 UI 验收尚未完成。单独重新安装插件不会更新宿主：

- `api.write.run("panels.openFile", { filePath })`：修饰键点击打开当前本地文档；不向插件返回文件内容。
- 使用 `api.write.domains()` 探测 `panels.openFile` 的授权；提供可靠任务历史但缺少导航动作的宿主仍显示任务统计和内联 diff，修饰键点击时提示缺少能力；缺少任务历史契约的旧宿主只显示兼容提示。此导航无需额外隐私声明，插件不请求其他写动作。
- 导航返回 `ok` 只表示请求被接受，不代表文件已成功读取；文件加载失败由宿主阅读器显示。

- 缺少回复插槽时不会加载卡片，也没有独立面板或聊天 DOM 注入替代。
- 插槽已加载但增强数据契约不满足时会提示升级；读取失败或缺少记录时不会展示假统计。
- **文件采集由宿主完成，插件只展示记录。**文件工具成功写入可以留下明确目标记录；终端采集主要比较命令执行前后、限定范围内的内容变化。
- 人工或外部进程并发修改、后台 / PTY、SSH、外部路径，以及同一命令内修改后恢复原样等，不保证被采集或正确归属。
- 扫描范围、文件数量、内容大小、时间预算、隐私过滤、结果截断与旧历史都可能导致缺口。Git 扫描排除 ignored；非 Git 扫描也会排除常见构建、依赖目录和符号链接等。

**数量仅代表已取得的记录，不是完整审计。没有记录不等于没有修改，已记录也不等于最终仍有净改动。**

## 隐私与开发参考

插件只读取宿主传入 `context.task` 的只读任务文件记录和覆盖快照，不读取消息正文，不扫描 Git、不执行命令、不联网、不修改项目文件，也不持久化路径或差异。卡片会显示宿主提供的文件路径；分享截图时请留意路径中可能包含的敏感信息。

运行入口是 `footer.js`，清单仅声明 `contributions.messageFooters`，`panels` 为空。宿主契约使用 `messageFooterVersion === 1`，清单显式声明 `taskHistory: true`，通过冻结的 `context.task: { id, records, coverage }` 读取本次任务证据；不再订阅累计 `runtime.fileChangeStats`。接口与生命周期详情请查阅 Snow App 内置文档「插件开发与安装」及「插件元数据域参考」。
