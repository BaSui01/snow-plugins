# 提示词优化 1.1.2

需配套宿主构建，UI/重启未验收。按对应专属标签下载安装包。

## 更新内容

- 草稿附带图片或截图时，优化器在改写指令中自动增强视觉引用保护（Attachment context），引导模型审阅图片、保留对视觉要素的引用，不误删图文关联词；回填时原图保持完整。
- Agent 运行期间可主动优化可编辑草稿，实时回复及运行/停止状态本身不使安全回填、应用与还原令牌失效；草稿实际变化、会话切换、不可编辑压缩及插件生命周期变化仍阻止旧结果覆盖新内容。
- 输入栏魔杖负责执行或取消优化，配置齿轮独立且默认隐藏；显示开关单独持久化，不保存未保存规则、不触发或取消优化。魔杖默认显示，不因隐藏齿轮而禁用插件。
- 优化完成后仍由用户主动发送，沿用宿主既有 queue / steer 策略；插件不自动发送、不修改队列条目，也不把优化规则写入聊天。

## 兼容性与验证边界

- Snow App v0.4.16 提供历史基础优化接口，但不代表上述运行中安全优化及齿轮契约已正式支持。新行为需要配套宿主构建，尚无已确认正式发行版本，不据此猜改市场最低版本。
- 本次版本与说明更新已通过现有 `python scripts/release.py validate`（两个插件清单、资源、JSON 与 JavaScript 语法）及 `git diff --check` 静态校验；不代表安装、真实 UI、重启持久化或 queue / steer 交互验收。
- 仅安装插件不会更新宿主。旧宿主可能继续禁用运行中优化、忽略齿轮声明并显示齿轮；不通过聊天 DOM 或普通聊天替代缺失能力。
- 点击魔杖仍可能向明确选择的模型服务发送草稿及所选上下文并产生费用；不读取密钥或附件，不持久化草稿与结果。
