# 提示词优化 1.3.0

模型下拉改为读取渠道全量模型清单。需配套宿主构建（`apiModels` 元数据域），UI/重启未验收。按对应专属标签下载安装包。

## 更新内容

- **模型下拉读取渠道全量模型**：面板不再只显示宿主档案里已配置的「基础模型 / 高级模型」两个字段。打开面板、切换服务或点击「重新读取服务」时，插件通过新增的宿主 `apiModels` 元数据域拉取该服务渠道实际提供的模型清单，下拉展示「已配置模型 ∪ 渠道清单」的去重并集，可选择渠道中的其他模型。拉取由宿主用档案已保存的凭据完成，**只返回模型 ID，插件拿不到密钥**，覆盖 OpenAI 兼容 `/v1/models`、Gemini、Anthropic 与 OAuth 订阅渠道。
- **降级与错误边界**：渠道清单读取失败、渠道未返回模型、或运行宿主没有该域（旧宿主）时，只显示已配置模型并在卡片下方给出状态提示（含「重新读取服务」重试引导），不阻塞保存与执行，不静默改用其他服务。
- **执行前校验扩展**：所选模型不在非空渠道清单内时报「所选模型已失效」并停止；渠道清单不可读或为空时不拦截（模型是否存在交由服务端判定）。校验只在必要时才发起清单请求：所选模型已在档案的已配置模型内时不额外拉取。
- **打开面板可能产生一次出站请求**：模型清单请求只发送模型列表请求，不含草稿、上下文或密钥；插件隐私说明与清单 `note` 已如实披露。
- 交互与安全边界不变：只改写草稿、不执行、不编造；回填与还原仍走宿主安全草稿令牌；绝不自动发送消息。

## 兼容性与验证边界

- **`apiModels` 元数据域为本次配套新增的宿主能力，尚无已确认正式发行版本。** 旧宿主没有该域时插件自动降级为仅显示已配置模型并给出提示；不据此猜改市场最低版本。
- 本次版本已通过 `python scripts/release.py validate`（两个插件清单、资源、JSON 与 JavaScript 语法）、插件内 `npm run check`（`tsc --noEmit` + 构建产物一致性）、宿主 `npm run check`（`tsc --noEmit` + `cargo check`）与宿主文档检查静态校验；不代表安装、真实渠道网络、失败路径或重启持久化验收。
- 仅安装插件不会更新宿主。旧宿主继续按 1.2.0 行为工作；不通过聊天 DOM 或普通聊天替代缺失能力。
- 点击魔杖仍可能向明确选择的模型服务发送草稿及所选上下文并产生费用；不读取密钥或附件，不持久化草稿与结果。

# 提示词优化 1.2.0

源码重构为 TypeScript 并改善整体交互。需配套宿主构建，UI/重启未验收。按对应专属标签下载安装包。

## 更新内容

- **源码迁移到 TypeScript**：`src/` 下的模块（偏好与规则、服务读取、输入栏 Action、配置面板）经 `scripts/build.mjs` 打包为单个 `index.js`；宿主仍以 ESM 动态导入该入口，相对导入不参与运行时解析，安装包结构与加载方式不变。
- **配置面板层级统一**：原来吸底保存区用负外边距叠在卡片之外，视觉上「保存配置」与表单不在同一层，还会遮挡上方卡片。现在所有区块（含保存区）共用同一张卡片样式，保存区不再 `sticky`、不再带 `z-index` 与阴影，并在保存前显示当前服务与模型摘要。
- **聚焦环不再外溢**：`outline-offset` 由正值改为负值，键盘聚焦环画在控件内侧，不再越出卡片边框悬浮在相邻元素上。
- **输入栏状态精简**：执行期间主按钮只显示转圈；回填成功后不再额外显示会被截断的「已回填，可还原…」文字，成功反馈由宿主「还原」按钮承担；「还原」按钮不再因容器过窄而竖排换行。（本条描述的是 1.2.0 早期实现；**最终实现见下方「输入栏完全静默」**，状态文字已彻底不显示。）
- **上下文是否生效可自证**：面板「上下文与模型」新增实时提示，订阅宿主 `runtime` 域（live、无需额外隐私声明），明确区分四种情况——已绑定且有消息（显示将带入的轮数与**当前会话真实消息条数**）、已绑定但**会话内还没有消息**（琥珀色，本次不带入）、策略为「仅草稿」、以及**新会话**（琥珀色）。`runtime.chatInput.conversationId` 与 Action 捕获草稿取的是宿主同一个变量，提示因此与实际执行一致；消息条数取 `runtime.conversation.messageCount`，仅在焦点会话与绑定会话相同时采信，不使用默认指向焦点会话的敏感 `messages` 域。提示随会话切换实时刷新。
- **输入栏完全静默**：执行、回填成功、**失败、还原失败**都不再显示任何状态文字，工具栏只保留转圈与「还原」按钮（`onStatus("")` 清空宿主默认的「执行中…」；失败抛出无消息错误，宿主渲染 `error.message` 为空即不显示）。失败原因不再内联提示，需从右侧面板的配置状态排查。
- **宿主：上下文变更不再残留提示**：`ChatInputPluginAction` 在上下文变更时清空状态而非设置 `stale` 文案，并移除随之无引用的 `stale` 标签；此项需重新构建 Snow App 才生效。
- **默认优化提示词重写为分节规则**：出厂默认值（三个语言包同步）改为分节结构，明确「输入是 JSON 对象、draft/history 字段」，用列表逐条列出必须原样保留的内容，并新增一条关键防线——「其后给出的策略、长度与表达结构偏好只影响风格与组织方式，不得用来削弱上述保留项」，避免模型以「精简」为由删掉有效约束、或以「展开」为由补造内容。中文约 530 码点、英文约 1600 码点；合并后完整规则中文约 1300、英文约 2400 码点，含图再增约 380，远低于 8000 上限。
- **策略差异写入自述文档**：插件 `README.md` 新增规则拼接顺序（宿主底线 → 公共偏好 → 您的规则 → 策略 → 长度 → 结构）与四策略 × 三长度 × 两结构的注入语义对照表，并标出两处冲突组合（「精简去冗余 + 适度展开」互相抵消；「结构化任务」的标题由表达结构决定而非策略）。
- **执行期间文案调整**：`generating` 改为「正在优化…再次点击魔杖可取消。」，原稿保护仍由草稿令牌保证，不因文案变化而放宽。
- 交互与安全边界不变：只改写草稿、不执行、不编造；回填与还原仍走宿主安全草稿令牌；绝不自动发送消息。
